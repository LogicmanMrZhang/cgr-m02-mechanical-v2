# CGR-M02 · 机械助力 V2

独立发布的 Three.js 交互式概念模型。

- [交互演示](https://logicmanmrzhang.github.io/cgr-m02-mechanical-v2/)
- [模型说明与截图](https://logicmanmrzhang.github.io/cgr-m02-mechanical-v2/model.html)

手柄、活动构件、定长连杆、曲柄、同步轴、左右凸轮及钢索弹簧由同一个行程进度联动。支持完整往返、暂停、任意进度、慢速、自由视角、部件高亮和结构隐藏。

P、O、S 为待确认的概念接口，比例和参数并非实测安装尺寸。此模型不代表已经验证的省力率或工程性能。

此仓库仅包含静态发布产物，JavaScript/CSS 与本地完成验证的构建一致。原参考仓库和冻结的电动化 V5 未作修改。

可使用任意静态 HTTP 服务运行本目录。GitHub Pages 从 main 分支根目录发布；.nojekyll 用于直接分发静态文件。第三方许可见 THIRD_PARTY_LICENSES.txt。
